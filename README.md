# Research Paper Simplifier

أداة بايثون تاخذ ورقة بحثية (PDF) وتطلع:
1. ملخص مبسّط لكل قسم (Introduction, Methods, Results...)
2. قائمة بالمصطلحات التقنية الصعبة مع السياق اللي ظهرت فيه
3. تقرير يقارن سهولة القراءة قبل وبعد التبسيط (Flesch Reading Ease)

## لماذا هذا المشروع؟

الأوراق البحثية مكتوبة بلغة متخصصة جدًا، وأي شخص يدخل مجال جديد
(أو حتى باحث بمجال مختلف) يصرف وقت طويل بس يفهم المصطلحات الأساسية.
هذي الأداة تحاول تسد هالفجوة.

## كيف تشتغل تقنيًا (مو مجرد استدعاء API)

- **استخراج النص**: PyMuPDF مع معالجة خاصة للأعمدة المزدوجة والكلمات
  المقسومة بنهاية السطر (hyphenation).
- **تقسيم الأقسام**: regex يتعرف على عناوين الأقسام الشائعة
  (Abstract, Methods, Results...) ويقسم النص بناءً عليها.
- **اكتشاف المصطلحات الصعبة**: spaCy لاستخراج noun phrases، مع فلترة
  حسب التكرار داخل الورقة نفسها (مصطلح يتكرر = على الأغلب مهم بالورقة).
- **التلخيص**: خوارزمية TextRank الاستخراجية (extractive) — تبني رسم
  بياني من الجمل وتختار الأكثر مركزية، بدون استدعاء أي نموذج لغوي خارجي.
- **قياس الجودة**: Flesch Reading Ease score يثبت رقميًا أن النص
  فعلاً صار أسهل قراءة.

## التثبيت والتشغيل (سطر الأوامر)

```bash
pip install -r requirements.txt
python main.py path/to/paper.pdf
```

## التشغيل كواجهة ويب (Streamlit)

```bash
pip install -r requirements.txt
streamlit run app.py
```

راح يفتح لك متصفح تلقائيًا برابط محلي، ترفع منه ملف PDF وتشوف النتائج مباشرة.

## هيكل المشروع

```
paper_summarizer/
├── app.py              # واجهة الويب (Streamlit)
├── pdf_extractor.py    # استخراج النص وتقسيمه لأقسام
├── term_extractor.py   # اكتشاف المصطلحات الصعبة
├── summarizer.py        # التلخيص + تقرير سهولة القراءة
├── main.py              # نقطة الدخول لسطر الأوامر
└── requirements.txt
```

## أفكار للتطوير لاحقًا

- واجهة ويب بسيطة (Flask/Streamlit) لرفع PDF مباشرة
- دعم تحميل الأوراق مباشرة من رابط arXiv
- قاموس مصطلحات تراكمي: كل ورقة تُعالَج تضيف مصطلحات جديدة لقاعدة بيانات مشتركة
- شرح المصطلحات تلقائيًا (مو بس اكتشافها) عبر ربطها بتعريفات من Wikipedia API
